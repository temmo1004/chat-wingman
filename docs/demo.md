# Demo 彩排腳本 & Pitch

給負責上台的人（D）。目標：90 秒內讓評審記住「軍師浮在戰場上」。

## 一句話 pitch

> 交友軟體上快被句點時，別離開聊天室——點一下浮在畫面上的軍師球，
> 它讀懂對話、給你三種風格的回覆和「為什麼這樣回」，一點就複製貼上。
> 外掛不在遊戲裡，軍師就在戰場上。

## Demo 流程（現場操作順序）

1. **鋪陳痛點**（15s）：秀一張「已讀不回 / 只回哈哈」的聊天截圖，
   「這種快聊死的對話，大家都遇過吧？」
2. **叫出軍師**（10s）：畫面上浮動球一直都在 → 點它
3. **見證救場**（20s）：面板彈出 → 指著**聊死指數 78**（「AI 也覺得快涼了」）
   → 三張卡片：認真 / 幽默 / 曖昧，各有一句**軍師解說**
4. **一點成真**（15s）：點「幽默」那張 → 回覆自動填進輸入框（或已複製）
   → 按送出，對話救回來
5. **收尾**（20s）：「同一顆腦，Android 是原生浮動球，iOS 是系統小白點捷徑，
   跨平台。競品都要你切出去上傳截圖，我們少四個步驟。」

## 差異化三句（評審會問「跟 Rizz 差在哪」）

1. **不離開聊天室**：競品都要切出去上傳截圖，我們球浮在 LINE 上點一下就地解決
2. **教你為什麼**：不只給句子，還給軍師解說——定位是教你聊天，不是幫你聊天
3. **聊死指數**：把對話熱度視覺化，一眼看到危機

（合規備答見 docs/deep-research.md：我們不碰 LINE API、不自動送訊，只做
OS 層截圖＋剪貼簿，用戶自己按送出。）

## 防翻車清單

- [ ] app 用 **DEMO_ONLY=true** build，全程本地假資料，**斷網也能演**
- [ ] MuMu 用 **Android 12（API 32）**，MediaProjection 規則寬
- [ ] 三權限（overlay + 無障礙 + 截圖）demo 前**先全部開好**
- [ ] 浮動球位置喬到不擋輸入框
- [ ] 準備 2-3 張經典「快被句點」對話截圖當背景
- [ ] 若填字在該 app 失效 → 自動退剪貼簿，話術照樣講「一鍵複製」

## 假對話截圖清單（C 準備）

1. 交友軟體剛配對，對方冷淡只回「嗯嗯」
2. 聊到一半話題斷掉，已讀不回
3. 曖昧期想升溫但不知怎麼接

每張都先跑過一次確認面板效果，別現場才第一次跑。
